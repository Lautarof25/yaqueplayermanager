# YAQUE Player Manager — Identidad eléctrica

Landing page estática para YAQUE Player Manager, desarrollada en HTML, CSS y JavaScript sin dependencias de compilación.

## Archivos
- `index.html`: estructura y contenido de la landing page.
- `styles.css`: identidad visual, responsive y animaciones.
- `script.js`: menú móvil, fichas emergentes de jugadores y animaciones de entrada.
- `assets/yaque-logo.jpg`: logo original proporcionado.
- `assets/juegadores/`: fotografías de los siete jugadores representados.
- `assets/favicon.svg`: favicon en negro y azul eléctrico.

## Ver localmente
Abrí `index.html` directamente en Chrome o Firefox. También podés usar la extensión Live Server de VS Code si preferís un servidor local.

## Publicar en Netlify
Arrastrá la carpeta del proyecto (o el ZIP descomprimido) a Netlify Drop. No necesita `npm install`, build ni dependencias externas.

## Personalización pendiente
Las siete fichas muestran fotografías y nombres. Para ampliar cada perfil, agregar posición, club actual, trayectoria y datos deportivos confirmados.

Las tipografías se cargan desde Google Fonts; si no hay conexión, se utilizan fuentes de respaldo del sistema.
